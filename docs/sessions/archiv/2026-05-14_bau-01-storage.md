## Was getan wurde

### 1. `src/modules/01_storage.js`

IIFE-Modul, klassisches `<script>`-Tag (kein ESM-Import). Klaus
arbeitet bevorzugt mit PWAs als Single-File-`index.html`, daher
ist die Copy-Paste-Variante in einen `<script>`-Block die bessere
Wahl als ESM mit `import`-Pfaden.

- **Öffentliche API:** registriert auf `window.SbkimStorage`
  mit allen sieben Funktionen aus der Spec
  (`init` / `getStore` / `get` / `put` / `del` / `all` / `clear`).
  Zusätzlich `_meta` mit `dbName` / `dbVersion` / `storePrefix` /
  `knownStores` für Diagnose.
- **`init()`:** Promise-cached (`dbPromise`-Singleton, idempotent
  bei Mehrfach-Aufruf). Öffnet die IDB-Datenbank `sbkim` mit
  `DB_VERSION = 1`. Migrations-Handler ruft `applyMigration(db, v)`
  für jede neue Version auf.
- **`applyMigration(db, version)`:** Für `v=1` werden alle sechs
  Stores aus der Spec angelegt
  (`sbkim_keys`, `sbkim_spore`, `sbkim_siblings`,
  `sbkim_anastomosis_log`, `sbkim_legacy_inbox`, `sbkim_doku_meta`).
  Wenn ein Store bereits existiert, wird er nicht überschrieben.
  Künftige Migrationen ergänzen Stores additiv.
- **`get/put/del/all/clear`:** alle prüfen den Store-Namen synchron
  via `assertKnownStore` (wirft `UnknownStoreError` synchron beim
  unbekannten Store), dann öffnen sie ihre eigene Transaktion. `all`
  iteriert per Cursor, weil das in älteren Safari-Versionen stabiler
  ist als `getAll()`.
- **`getStore(storeName)`:** synchroner Helfer; gibt ein Objekt mit
  an den Store gebundenen Methoden zurück. Bewusst keine Promise-
  Rückgabe, weil die Spec das so vorsieht (sync handle).
- **Fünf Error-Typen:** `makeError(name, message, cause)`-Helfer
  baut Standard-`Error`-Instanzen mit gesetztem `.name` und
  optionalem `.cause`. `StorageUnavailableError`,
  `UnknownStoreError`, `QuotaExceededError`, `DataCloneError`,
  `StorageOpenError` — alle mit deutschsprachiger Message.
- **Selbstcheck:** beim Skript-Laden, synchron, vor jedem
  `init()`-Aufruf:
  `console.info("MODUL 01 STORAGE bereit, Funktionen: init/getStore/get/put/del/all/clear")`.
  Format genau wie in der Spec.

JS-Syntax mit `node --check src/modules/01_storage.js` validiert
(grün).
