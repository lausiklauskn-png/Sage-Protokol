# Notiz — Vom Briefkasten zur Pinnwand (was schon läuft, was fehlt)

> Kurz und geerdet: belegt aus den echten Dateien in `sbkim/`, nicht aus dem
> Gedächtnis. Frage dahinter: Ist die „verteilte Pinnwand" weiter, als sie wirkt?

## Was schon LÄUFT (Belege)

- **Dummes gemeinsames Brett:** Nachrichten liegen als Dateien (`SIGNAL.json`,
  `AUSTAUSCH-*.md`) im Repo, gelesen über feste `raw`-Links. **„Das Pushen IST
  das Signal"** — ein immer erreichbares Brett, das nichts rankt, nichts verkauft.
- **Visitenkarte als Vektor:** jeder Knoten hat `spore.json` mit `domainVector`
  (namenlose Interessen-/Domänen-Karte).
- **Erkennen nach Bedeutung über das Netz:** Status `verified-match` = beide
  Karten verglichen, semantisch **≥ 0,80**, beidseitig real gemessen
  (Rezeptbuch 0,82 · Mixarium 0,81 · KIMTool-Point 0,85 · Jasons-Tresor 0,85).

→ Das Kern-Prinzip (Karten erkennen sich server-los über ein dummes Brett nach
Bedeutung) ist in einem kleinen, handgebauten Kreis **bereits bewiesen.**

## Wo Briefkasten und Pinnwand sich unterscheiden

- **Briefkasten = adressierte Post** (A schreibt gezielt an B + Quittung).
- **Pinnwand = offenes Brett** (ins Gemeinsame hängen; **Fremde** finden mich
  nach Bedeutung). Der Transport (push=Signal) ist wiederverwendbar; die
  *offene Such-über-Fremde*-Schicht fehlt (= noch unbewiesene Cross-Knoten-Suche,
  Modul 04.C + 15).

## Die ZWEI fehlenden Brücken (das eigentlich Verkaufbare)

1. **Selbst-Anmeldung beim Installieren** — Karte erzeugt sich beim ersten Start
   selbst, kein GitHub-Repo, kein Mensch-als-Briefträger.
2. **Ein Brett für Normale** — auf das man ohne GitHub schreiben kann. Heute ist
   das Brett GitHub (geht für Technik-Leute, nicht für die Oma). Das heißt fast
   sicher: **ein kleines, dummes Stück Infrastruktur** — machtlos (liest/rankt/
   verkauft nicht), aber nicht „null".

## Such-Werkzeug + Briefkasten = die zwei Hälften

- **Such-Werkzeug = die Augen/Brille:** macht aus „was ich will" einen Vektor und
  sortiert nach Bedeutung. (Aktuell sucht es im **lokalen** Knoten-Korpus
  `sage-knoten-korpus.js` — ein Abzug, noch nicht live.)
- **Briefkasten = Brett + Postweg:** Transport + Identität + dummes Brett.
- **Pinnwand = beide zusammen, verdrahtet:** „ich suche" → geht als Anfrage übers
  Brett raus → Antworten kommen zurück, nach Bedeutung sortiert. Diese **eine
  Verdrahtung** (Modul 04.C + 15) ist der fehlende Draht — beide Hälften gibt es
  schon getrennt.

## Ehrliche Grenzen (unverändert)

- **Leere am Anfang** → in EINEM Kreis starten (Verein/Nische/Ort), nicht „für alle".
- **Vertrauen** → leichte Tausche (lokal, abholen, verschenken), kein Geld an Fremde.
- **Brett = heute GitHub** → für Normale braucht es ein eigenes dummes Brett.
